# Circuits Brio

Application web pour concevoir des circuits de train en bois (Brio) avec ses propres pièces, pensée pour l'iPad.

## Fonctions

- Pose de rails (droits, courbes, aiguillages), rampes, ponts, tunnel, gare, commissariat et reliefs
- Inventaire des pièces possédées, avec photos
- Contrôle de la fermeture du circuit, des raccords mâle/femelle et des chevauchements
- Génération automatique de circuits à partir de l'inventaire
- Liste de montage et export PDF (plan et guide)
- Sauvegarde dans le navigateur, export et import de fichiers `.json`

## Utilisation

Ouvrir `index.html` dans un navigateur, ou utiliser la version hébergée avec GitHub Pages.
Les circuits sont enregistrés localement sur l'appareil ; aucun compte n'est nécessaire.

Sur iPad : ouvrir la page dans Safari, puis Partager > Sur l'écran d'accueil.

## Publication avec GitHub Pages

Dans le dépôt : Settings > Pages > Source « Deploy from a branch », branche `main`, dossier `/ (root)`.
